# 水印相机交互演示

依据 [Figma 水印相机](https://www.figma.com/design/TwvnLieEu7DSTdVf2vPtPf?node-id=1-2) 的 22 个页面及弹层状态制作，读取日期：2026-10-22。Figma 未被修改，仍是设计事实源。

## 打开演示

直接打开 `水印相机-交互演示.html`。此文件内嵌全部样式、脚本和界面数据，不依赖开发服务器、网络字体或图片资源。也可通过本地静态服务器查看 `index.html`。浏览器验证通过本地 HTTP 进行，未直接验证 file 协议。

- 桌面左侧「页面」可进入全部场景，右侧为完整手机屏幕。
- 手机顶部点「菜单」展开控制台，选择页面后自动收起；「首页」返回业务首页。
- 「状态」可设置断网、慢速、持续加载、下一次失败和模拟权限。
- 「事件」可手动完成或取消加载、恢复网络、加入示例记录。
- 编辑完成后仍需点照片或模板的「保存」。已保存内容在当前浏览器刷新后恢复。场景快捷入口使用示例数据，不清空用户记录。
- 「重置演示」需要二次确认，只清除此演示自己的数据。

## 页面关系与实现计划

主流程：

```
首页 → 相机 → 拍照 → 照片详情 → 编辑照片 → 保存 → 照片详情 → 首页有记录
  ├→ 水印模板 → 模板中心 → 模板预览 → 使用模板 → 相机
  │                       └→ 我的模板 → 字段编辑 / 添加字段 → 保存模板
  ├→ 图片验证 → 输入编号 → 查询 → 验证结果
  └→ 全部 → 批量管理 → 选择 / 全选 → 分享或删除
相机 → 拍摄设置 → 画幅 / 定时 / 网格线 / 验证水印 / 地点
相机 → 画中画拍摄 → 拍照 → 照片详情
编辑照片 → 添加或选中水印 → 时间格式 / 地点 / 备注 / 更换模板
编辑照片 → 画中画编辑 → 形状 / 边框 / 拖动 → 完成
编辑照片 → 裁剪 → 比例 → 完成或取消
```

实现顺序为还原原稿布局与文案、接通上述主流程、加入可保存的演示状态及异常、检查桌面与手机。完整场景清单及进入前提、行为、异常见 `scenarios.json`。

## 模拟边界与设计冲突处理

- 相机、定位、照片内容、相册保存、验证结果使用本地示例，不请求真实设备权限，不访问业务 API，不发送信息。
- 验证成功示例编号为 `AIO-20261019-1342`，并非真实查验服务；其他编号显示模拟的未找到提示。
- 原稿没有 reactions、原生 annotations 或画布旁交互说明。页面关系依据标题、控件和状态稿推断。
- 没有设计稿的相册导入、替换照片、视频拍摄、模板搜索、系统分享、其他月份使用 Toast 拦截。
- 照片编辑中的画中画入口先用 Toast 说明选图页缺稿，使用原稿中的示例小图进入已有画中画编辑页，以便演示该页面；不虚构相册选择页面。
- 拍摄、保存、验证、定位和批量删除有加载、失败和恢复；真实文件生成、照片像素处理、反伪校验不在演示范围内。裁剪通过占位区域和比例变化模拟。
- 场景菜单中的空记录和有记录是原稿状态预览；空状态快捷入口不会删除已有数据。直接进入照片场景时可使用示例照片。
- 原稿首页日期为 10 月 20 日，拍摄照片为 10 月 19 日，全部图片稿列出 15 张缩略图；保留这些设计文案。演示事件产生的记录采用本地记录状态。
- 原稿水印预览显示备注，水印选中稿的备注开关为关闭。演示统一为同一业务开关，默认展示备注，调整后各页面保持一致。
- 字段样式、时间、地点、备注可编辑。水印和画中画位置可拖动；比例、颜色、透明度、开关均有可观察反馈。

## 文件

- `水印相机-交互演示.html`：交付的独立成品。
- `index.html`、`app.js`、`style.css`：可维护的应用源文件。
- `design-data.json`：本次从 Figma 读取的界面数据快照，不用于反向同步或维护 Figma。
- `scenarios.json`：22 个场景与源 node ID 的关系清单。
- `build.py`：运行 `python3 build.py` 重新生成独立 HTML。
- `验证记录.md`：实际完成的浏览器验证。
